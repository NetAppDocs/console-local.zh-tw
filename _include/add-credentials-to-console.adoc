安裝並設定 Console 代理程式後，新增您的雲端認證資料，以便 Console 代理程式擁有在 AWS 或 Azure 中執行行動所需的權限。

[role="tabbed-block"]
====
.AWS
--
.開始之前
如果您剛剛建立了這些 AWS 憑證，它們可能需要幾分鐘才能生效。請稍等幾分鐘，再將憑證新增至 Console。

.步驟
. 選擇 *Administration > Credentials*。
. 選擇*組織憑證*。
. 選擇 *Add Credentials* ，然後依照精靈中的步驟操作。
+
.. *憑證位置*：選擇 *Amazon Web Services > Agent*。
.. *定義憑證*：輸入 AWS 存取金鑰和秘密金鑰。
.. *Marketplace Subscription*：立即訂閱或選擇現有訂閱，將 Marketplace 訂閱與這些認證資料建立關聯。
.. *審核*：確認新憑證的詳細資訊，然後選擇*新增*。




現在您可以前往 https://console.netapp.com["NetApp Console"^]開始使用 Console 代理程式。

--
.Azure
--
.開始之前
如果您剛剛建立了這些 Azure 憑證，它們可能需要幾分鐘才能生效。請稍等幾分鐘，然後再將憑證新增至 Console 代理程式。

.步驟
. 選擇 *Administration > Credentials*。
. 選擇 *Add Credentials* ，然後依照精靈中的步驟操作。
+
.. *憑證位置*：選擇 *Microsoft Azure > 代理程式*。
.. *定義憑證*：輸入授予所需權限的 Microsoft Entra 服務主體的相關資訊：
+
*** 應用程式（用戶端）ID
*** 目錄（租戶）ID
*** 用戶端密碼


.. *Marketplace Subscription*：立即訂閱或選擇現有訂閱，將 Marketplace 訂閱與這些認證資料建立關聯。
.. *審核*：確認新憑證的詳細資訊，然後選擇*新增*。




.結果
Console 代理程式現在擁有代表您在 Azure 中執行行動所需的權限。您現在可以前往  https://console.netapp.com["NetApp Console"^] 開始使用 Console 代理程式。
