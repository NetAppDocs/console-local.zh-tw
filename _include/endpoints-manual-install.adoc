要取得映像，安裝程式需要存取以下兩組端點之一。^1^ 建議使用選項 1 中列出的端點，因為它們更安全。我們建議您設定防火牆，允許存取選項 1 中所列的端點，同時禁止存取選項 2 中所列的端點。請注意以下關於這些端點的事項：

* 從 Console 代理程式的 3.9.47 版本開始，支援選項 1 中列出的端點。與 Console 代理程式的先前版本不相容。
* Console 代理程式首先聯絡選項 2 中所列的端點。如果這些端點無法存取，Console 代理程式會自動聯絡選項 1 中列出的端點。
* 如果您將 Console 代理程式與 NetApp Backup and Recovery 或 NetApp Ransomware Resilience 搭配使用，則選項 1 中的端點不受支援。在此情況下，您可以拒絕選項 1 中列出的端點，同時允許選項 2 中列出的端點。
