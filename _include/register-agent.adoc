登入 Console 並將 Console 代理程式與您的組織建立關聯。登入方式取決於您使用 Console 的模式。如果您以標準模式使用 Console，則透過 SaaS 網站登入。如果您以受限模式或私有模式使用 Console，則從 Console 代理程式主機本機登入。

.步驟
. 開啟網頁瀏覽器，輸入 Console 代理程式主機 URL：
+
Console 主機 URL 可以是本機主機、私有 IP 位址或公用 IP 位址，取決於主機的組態。例如，如果 Console 代理程式位於沒有公用 IP 位址的公有雲中，則必須輸入與 Console 代理程式主機有連線的主機的私有 IP 位址。

. 註冊或登入。
. 登入後，設定 Console：
+
.. 指定要與 Console 代理程式關聯的 Console 組織。
.. 請輸入系統名稱。
.. 在「您是否在安全的環境中運作？」下，保持受限模式停用狀態。
+
當 Console 代理程式安裝在本機時，不支援受限模式。

.. 選擇 *Let's start*。
