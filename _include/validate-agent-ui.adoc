如果在「審查」頁面上選取了「驗證代理程式組態」核取方塊，Console 會在建立代理程式後驗證其組態。如果 Console 無法部署代理程式，它會提供可下載的報告，協助您進行疑難排解。


NOTE: 如果 Console 成功部署代理程式，則不會產生報告，並且會出現確認對話框，驗證部署是否成功。

.步驟
. 在「代理程式部署失敗」對話方塊中，選取「下載報告」以下載包含驗證報告的 PDF 檔案。
. 或者，您可以選擇 *Start over* 返回 *Deploy agent* 精靈並重試。
+
如果想再次部署代理程式，則必須重新開始整個過程。
