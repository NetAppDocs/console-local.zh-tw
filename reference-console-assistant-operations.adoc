= 在 NetApp Console 本機部署中支援的 Console 助理操作
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
在 NetApp Console 本機部署中使用 Console 助手，您可以提出自然語言問題並執行選定的儲存設備操作。可用操作取決於您被指派的存取角色。注意：本文件說明如何將 LLM 連接至 Console 助手以啟用 AI 功能，目前僅提供技術預覽版。對於此預覽產品，NetApp 保留在正式發布前修改產品詳情、內容和時間表的權利。

對於無需更改基礎架構的問題和分析，請使用 Console 助手的「唯讀」模式。對於可能變更儲存設備或 ONTAP 系統的支援操作，請使用「讀取/寫入」模式。助手會顯示建議的變更，並在執行寫入作業前要求確認。



[[console-assistant-capabilities]]
== Console 助手功能

Console 助手支援以下操作類別。可用操作取決於您的版本、已設定的 LLM 端點、指派的角色和資源範圍。

[cols="28,18,54"]
|===
| 功能 | 存取模式 | 用它來 


| 對話式指導與搜尋 | 唯讀 | 詢問有關 NetApp Console 本地部署、儲存環境及支援的 ONTAP 管理工作流程的問題。 


| 計量與分析 | 唯讀 | 在允許的範圍內，分析支援的容量、效能和其他計量。 


| 儲存資源配置 | 讀取/寫入 | 在審查並確認擬議作業後，規劃和資源配置支援的 Volume 或 LUN。 


| 警報調查和補救 | 唯讀或讀寫 | 在更改儲存設備之前，調查作用中警報並審查支援的補救措施。 


| ONTAP 管理 | 唯讀或讀寫 | 檢視或對與 Console 關聯的系統執行受支援的管理作業。 
|===
使用您指派的角色以及組織、資料夾或機組範圍來確定助理可以存取哪些系統和工作負載。助理不會繞過 Console 本機部署存取控制。



[[metrics-and-analytics]]
== 計量與分析

詢問您權限範圍內資源的儲存容量、效能及其他計量的唯讀問題。如果這些細節與您的問題相關，請提供資源、計量和時間段。

助手傳回分析結果，但不會以*唯讀*模式變更儲存設備。

使用 Console 助理可以進行自然語言查詢，並對授權範圍內的資源進行高階分析。當您需要對單一 Volume 進行詳細的時間型分析時，請使用 Workload Analyzer，分析內容包括延遲、處理量、資源使用率、容量、事件和預測。link:concept-workload-analyzer.html["了解工作負載分析器。"]



[[storage-provisioning]]
== 儲存資源配置

請用自然語言描述工作負載及其儲存設備需求。助理可以推薦儲存設備類別和放置位置、識別缺少的詳細資訊，並提供資源配置方案供審查。

批准計劃後，助手將根據您的角色權限和儲存類別原則，佈建受支援的 Volume 或 LUN 作業。link:task-provisioning-agentic.html["了解如何使用人工智慧輔助工作流程資源配置儲存設備"]。



[[alert-investigation-and-remediation]]
== 警報調查和補救

請助手調查作用中警報。它會分析警報並可能建議補救行動。如果支援的補救措施會更改儲存設備，助手會顯示該行動供審查，並在執行前要求您確認。

在助理變更儲存設備之前，請審查建議的補救措施詳細資訊並確認該行動。

link:reference-alert-remediation.html["了解警報補救措施。"]



[[ontap-management]]
== ONTAP 管理

使用自然語言請求對已註冊的 ONTAP 系統執行受支援的管理作業。如果您知道目標叢集、儲存虛擬機器 （SVM） 或資源，請提供相關資訊，以便助理能夠使用正確的內容。

請審查您的要求是僅讀取資訊還是變更 ONTAP 系統，然後確認任何擬進行的寫入作業。可用的操作集取決於 Console 本機部署版本以及指派給您帳戶的權限。

link:task-console-asst-use.html["了解如何使用 Console 助手。"]



[[permissions-and-scope]]
== 權限和範圍

助理使用已登入使用者的權限和資源範圍。您指派的組織、資料夾或機組範圍決定了助理可以存取哪些系統和工作負載。

* 您的角色決定了您可以檢視或變更哪些資源和作業。
* 儲存類別原則限制了 AI 輔助的儲存資源配置。
* 助理不會繞過 Console 本機部署存取控制。


link:reference-iam-predefined-roles.html["了解 NetApp Console 本機部署存取角色"]。



[[asynchronous-operations]]
== 非同步作業

向助手查詢非同步執行的受支援寫入作業的狀態。助手會為不會立即完成的作業建立一個工作。
