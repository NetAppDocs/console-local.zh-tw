= 稽核 NetApp Console 本地部署活動
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
在法規遵循審查期間記錄管理活動，以驗證存取變更並保存跨 NetApp Console 本機部署的行動記錄。

.所需角色
超級管理員、組織管理員、資料夾和機組管理員、維運支援分析師、超級檢視器、組織檢視器或資料夾和機組檢視器。link:reference-iam-predefined-roles.html["了解存取角色"]。

您可以在 Console 本機部署中檢視稽核活動，並下載稽核日誌的 CSV 檔案。



[[audit-user-activity-from-the-audit-page]]
== 從「稽核」頁面稽核使用者活動

在解決事件或驗證操作責任時，監控管理活動以追蹤 NetApp Console 本機部署中的變更。

「稽核」頁面顯示使用者在組織內完成的行動。例如，您可以驗證是誰向組織新增了成員，確認使用者是否刪除了機組，或檢視使用者在組織內執行的其他儲存管理行動。

稽核日誌顯示以下服務的活動：

* 租戶：與管理您的組織相關的行動，例如新增使用者、建立機組和關聯資源。
* 儲存管理：與管理儲存資源相關的行動。
* 聯盟：與管理聯盟相關的行動，例如建立聯盟以及新增或移除聯盟組織。


.步驟
. 選擇「管理 > 稽核」。
. 使用表格上方的篩選器，依時間範圍、服務、行動、資源、使用者或狀態縮小稽核活動的範圍。


稽核條目會在能夠確定使用者身分的情況下顯示執行行動的使用者。如果無法確定使用者身份，條目則會顯示使用者的 `auth0Id`，而不是其姓名。

例如，您可以使用 *服務* 篩選器顯示與特定服務相關的行動，或者使用 *使用者* 篩選器顯示與特定使用者帳戶相關的行動。



[[filter-audit-logs-for-identity-and-access-management-actions]]
=== 篩選身分和存取管理動作的稽核日誌

審查存取管理變更，以確認誰修改了組織資源，並支援準確的安全性調查。

.步驟
. 選擇「管理 > 稽核」。
. 使用篩選器縮小搜尋結果範圍。選擇 *Service* ，然後選擇 *Tenancy* 。
. 使用其他篩選條件可以進一步精簡結果。
+
例如，使用 *使用者* 篩選器顯示特定使用者帳戶執行的 IAM 行動。





[[download-audit-logs-from-the-audit-page]]
=== 從「稽核」頁面下載稽核日誌

保留組織行動的獨立記錄，以支援法規遵循審查和未來的事件調查。下載的 CSV 檔案包含所有稽核日誌欄，即使您套用篩選器或變更顯示的欄。

.步驟
. 在「稽核」頁面中，選擇表格右上角的下載圖示。
