= 連接您的 LLM 並在 NetApp Console 本機部署中啟用 NetApp Console 助手
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
連接受支援的 LLM 端點，以便向 NetApp Console 本機部署使用者提供受治理的自然語言儲存設備指導和操作。


NOTE: 本文件說明如何將 LLM 連接至 Console 助理以啟用 AI 功能，此文件以技術預覽版形式提供。對於此預覽產品，NetApp 保留在正式發行前修改產品詳情、內容及時間表的權利。

.所需存取權限
超級系統管理員或組織系統管理員。link:reference-iam-predefined-roles.html["了解存取角色"]。

設定後，使用者從儀表板開啟 Console 助手並選擇存取模式：

* 在*唯讀*模式下，助理會回答問題並提供指導，但不會進行任何變更。
* 在 *Read/write* 模式下，助手可以對儲存基礎架構進行操作。每次變更之前，它都會顯示詳細資訊供審查和確認。對於非同步操作（例如建立 Volume），它會建立一個工作，使用者可以從助手檢視該工作。


若要連接您的 LLM，請選擇供應商路徑，輸入端點詳細資訊和 API 金鑰，然後在「管理 > AI 工具」中選擇模型。助手行動將遵守您的儲存設備原則和角色型存取控制。



[[gather-what-you-need-before-you-connect-an-llm]]
== 在連接 LLM 之前，請先準備好所需資料。

請準備供應商憑證和端點存取，以便 Console 助理可以在您組織設定的治理範圍內運作。

* 您的供應商類型選擇：OpenAI、OpenAI 相容或 Anthropic，取決於版本和端點的支援情況。
* 您所選供應商路徑的有效 API 金鑰。
* 您的供應商路徑的端點 URL。
* 如果需要，請提供您的 LLM 供應商帳戶使用者名稱或 ID。
* 從 Console 本機部署到所選端點的網路存取。


link:reference-llm-supported-models.html["了解 NetApp Console 本機部署中支援的 LLM 供應商和模型"]。



[[connect-an-llm-to-netapp-console-local-deployment]]
== 將 LLM 連線到 NetApp Console 本機部署

透過經過驗證的供應商組態啟用助手功能，同時保留對端點憑證的管理控制。

.步驟
. 登入 NetApp Console 本機部署。
. 選擇 *Administration > AI Tools*。
. 選擇選單，然後選擇*編輯*。
. 在「供應商類型」中，選取供應商類型。
+
link:concept-llm-integration.html["了解 LLM 在 NetApp Console 本機部署中的整合"]。

. 如果提示輸入供應商端點，請輸入您選擇的供應商路徑的端點 URL。
. 在「使用者名稱」欄位中，輸入您的使用者名稱或 SSO ID （如果您的供應商路徑要求）。
. 在「API 金鑰」欄位中，貼上您選擇的供應商路徑中的 API 金鑰。
. 從清單中選取型號。
. 審查組態，然後選擇 * 儲存 *。
+
儲存組態前，請審查供應商類型、端點 URL、API 金鑰和所選模型。





[[verify-that-llm-integration-works]]
== 驗證 LLM 整合是否正常運作

確認助理的可用度和核准行為，讓使用者能夠依賴已設定的整合來執行受管控的作業。

.步驟
. 以*唯讀*模式開啟 *Console assistant* 並執行基本查詢。
. 在*讀取/寫入*模式下開啟 *Console assistant*，並確認變更儲存設備的操作在執行前需要使用者確認。
. 確認需要行動工作流程的使用者是否擁有必要的角色型存取控制權限。


完成驗證後，使用者可以從儀表板開啟 Console 助手，並以簡單的語言描述工作。link:task-console-asst-use.html["了解如何使用 NetApp Console 助手"]。



[[protect-credentials-and-monitor-llm-usage]]
== 保護認證資料並監控 LLM 使用情況

保護 LLM 憑證並監控供應商活動，以減少未經授權使用整合的情況，並支援組織治理。

* 盡可能使用專用 API 金鑰進行 Console 本機部署整合。
* 根據貴組織的原則輪換 API 金鑰。
* 根據貴組織的治理要求，監控供應商端 API 使用情況和警示。
